# Prompt check

The learner writes the prompt for each step. When they write "check my
prompt", check it before you write code.

## What to check

1. Skill: the prompt, or the session before it, points you to the
   nvalchemi-toolkit skill.
2. Task: one clear thing to do.
3. Input: the data and models are named as the notebook names them.
4. Output: the learner asks for a specific result and gives the names they
   want back.

A named setting, or a request to explain your settings, is optional. Its
absence is fine.

## How to answer

One line per item: "ok", or what is missing, in a few words. Then one of:

- everything is there: say that the prompt is complete, and ask whether to
  go ahead;
- something is missing: ask the learner to add it, or to tell you to go
  ahead.

Keep the learner's wording. Suggest the missing piece; leave the rewrite to
them. Write no code until the learner tells you to go ahead.

## What the learner does not owe you

Shapes, units, file layout and Toolkit classes. Take these from the
nvalchemi-toolkit skill and from the step check, and state the ones you used
when you report.
