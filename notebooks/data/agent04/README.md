# Saved defaults of notebook 04, "Made to order"

## `alanine-dipeptide-grid.extxyz`

What: 139 starting structures of alanine dipeptide (Ace-Ala-NMe, 22 atoms
each, neutral) on a 12 by 12 grid of the backbone angles phi and psi, in
30 degree steps from -180 degrees. Each frame carries `phi`, `psi` (target
angles in degrees), `charge` (0) and `grid_points` (144). Five of the 144 grid
points are dropped because two atoms come closer than 0.7 Å.

Loader: `helpers.agent04.load_dipeptide_grid()` reads this file (`n=12`), and
prints "dipeptide grid: 139 of 144 starts kept (5 with clashing atoms
dropped)".

Source: generated, not downloaded. RDKit builds the all-trans molecule
`CC(=O)N[C@@H](C)C(=O)NC` from its SMILES with a fixed-seed embedding (seed
0xA1A, the first embedding whose two amides are trans) and an MMFF clean-up;
ASE sets phi and psi on the grid. No third-party structure data.

Licence: the structures are generated by course code (Apache-2.0). The tools
are RDKit 2026.3.4 (BSD-3-Clause) and ASE 3.27.0 (LGPL-2.1-or-later), listed
in `SOURCES_AND_LICENSES.md`.

How built: from `notebooks/`, with the runtime environment,

```text
python -c "from helpers import agent04; print(agent04.build_dipeptide_default())"
```

Check (SHA-256 of the file as saved): `a19f82135911ac7c0ec6b9a7009190b2665e6cd12e81a1780e20f433041f7556`.

Verification: all atoms are H, C, N or O, covered by the AIMNet2 checkpoint;
the 139 starts relax in one batch with the composed model, all of them to the
step's threshold
(`helpers.relax_settings()["fmax"]`, 0.01 eV/Å: 824 s on a CPU with 4 threads,
a few seconds on a GPU); `python -m helpers.agent04 check conformers` passes on
the sample solution.
